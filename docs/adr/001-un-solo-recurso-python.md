# ADR 001 · Un solo recurso principal de Python
Estado: recurso seleccionado por Carlos el 8 de noviembre de 2026.
Contexto: principiante que necesita continuidad y aplicación documental.
Decisión: Hello-Python de MoureDev, sección Fundamentos, como recurso principal.
Referencia complementaria: tutorial oficial de Python en español, capítulos 3–4.
Alternativa: varios cursos completos simultáneos; se mantiene una sola fuente principal.
Consecuencia: practicar sin mirar tras estudiar y explicar el código propio.
Carga de semana 1: vídeo 6,5 h, referencia 2 h y ejercicio 3 h.
Pendiente: verificar enlaces, acceso y unidades concretas; no acreditar consumo.
Norma: regla pedagógica interna CRAI; no es una norma jurídica.
