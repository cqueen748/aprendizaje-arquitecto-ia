# ADR 001 · Un solo recurso principal de Python
Estado: decisión de enfoque; selección del recurso pendiente.
Contexto: Carlos empieza a programar y necesita continuidad.
Decisión: usar un recurso principal de Python en español.
Alcance: prácticas de los meses 1–2 y consultas puntuales complementarias.
Alternativa: seguir varios cursos completos simultáneamente.
Consecuencia: evitar duplicar contenidos y registrar ejercicios aplicados.
Pendiente: fijar título, enlace, acceso y lecciones concretas.
Evidencia: progreso y explicaciones independientes de Carlos.
Norma: regla pedagógica interna CRAI; no es una norma jurídica.
