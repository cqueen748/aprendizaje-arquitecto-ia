## Práctica y aceptación
Usar `datos/expediente_prueba/`, dentro de la carpeta excluida de Git. Empezar con 8–10 archivos sintéticos (PDF, Word y alguno sin extensión); cualquier expediente real requiere autorización y manejo confidencial.
Carlos debe escribir el recorrido con `os` o `pathlib`, mostrar nombre, extensión y tamaño KB de cada archivo y al final contar por extensión.
Para revisar se requiere código, salida real y explicación independiente del recorrido y del conteo. No se entrega la solución por adelantado.
Antes de medir el tamaño, definir si KB representa 1000 bytes o si se usará KiB (1024 bytes); la salida debe corresponder a la unidad elegida.
Si no hay avance, repetir la semana 1 con alcance reducido: listar solo nombres. La fecha nominal de cierre no acredita cumplimiento.
